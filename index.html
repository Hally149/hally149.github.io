03 — security · prototype

SkyVault Security

A secure cloud storage prototype built around a real Node.js/Express backend: files are encrypted with AES-256-GCM, account passwords are hashed with PBKDF2, and access runs through session-based authentication — built for a university security module alongside a refined, production-feeling UI.

04 — smart mirror · group project

Aura Smart Mirror

A mood-aware smart mirror: a Flask backend reads emotion from a live camera feed and suggests music to match it, while a built-in detector flags misleading or exaggerated claims in text. Mood-reactive LEDs (driven by a Raspberry Pi) turn that same emotional read into ambient light, and a companion React Native + Firebase app carries it to mobile with mood tracking, guided me-time, and sleep tools.
